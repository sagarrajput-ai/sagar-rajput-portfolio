\## 🚀 Network Engineering Toolkit



The application currently includes:



\### IP / Subnet Calculator



Calculate important IPv4/IPv6 network information including:



\- Network address

\- Broadcast address

\- Netmask

\- Hostmask

\- First usable host

\- Last usable host

\- Total addresses

\- Usable hosts

\- Prefix length



\### Subnet Planner



Plan multiple subnets from an existing network and calculate:



\- Subnet number

\- Network address

\- Broadcast address

\- Netmask

\- Prefix length

\- First host

\- Last host

\- Usable hosts



\### IP Range Calculator



Calculate the total number of IP addresses between:



\- Starting IP

\- Ending IP



Supports both IPv4 and IPv6.



\### DNS Lookup



Resolve hostnames and retrieve:



\- Canonical hostname

\- Aliases

\- IP addresses



\### TCP Port Checker



Check whether a TCP port is reachable on a specified hostname or IP address.



The tool provides:



\- Host

\- Resolved IP

\- Port

\- Connection status
