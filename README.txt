# Sagar Rajput Professional Flask Portfolio

## Run locally
1. Open PowerShell in this folder.
2. Create/activate your virtual environment if needed:
   `python -m venv venv`
   `.env\Scripts\Activate.ps1`
3. Install dependencies:
   `python -m pip install -r requirements.txt`
4. Run:
   `python app.py`
5. Open:
   http://127.0.0.1:5000

The supplied resume PDF is included under `static/Sagar_Rajput_Resume.pdf`.
