HOW TO USE

How to plan IPv4 subnets

  1. Enter the network and CIDR.

    Type an IPv4 network such as 192.168.10.0/24 into the Network / CIDR field.

  2. Enter the required number of subnets.

    Type a number between 1 and 1024 into the Required Number of Subnets field.

  3. Click Generate Subnets.

    Submit the form to generate the subnet table.

  4. Review the subnet table.

    Each row shows the subnet number, network address, broadcast address, host range, mask and usable hosts.

Subnet Planner FAQ

What does the Subnet Planner do?

It splits an IPv4 network into the requested number of equally sized subnets and shows the network address, broadcast address, host range, subnet mask and usable hosts for each one.

What format should I enter for the network?

An IPv4 network in CIDR notation, such as 192.168.10.0/24.

How many subnets can I request?

Between 1 and 1024 subnets in a single calculation.

What happens if I request more subnets than the network can support?

The tool returns an error explaining that the network cannot be divided into the requested number of subnets at a valid prefix length.
