DNS Lookup FAQ

What does a DNS lookup do?

It resolves a hostname to its canonical name, any aliases, and its current IP addresses.

What is a canonical name?

The canonical name is the authoritative hostname associated with the DNS record, which can differ from the name you searched if the domain uses aliases.

What are DNS aliases?

Alternate hostnames, defined as CNAME records, that point to the same canonical destination.

What does the tool return?

Hostname, canonical name, any aliases, and the resolved IP addresses.
