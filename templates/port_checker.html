HOW TO USE

How to check TCP port connectivity

  1. Enter a hostname or IP address.

    Type the target host, such as example.com or 192.168.1.1.

  2. Enter the TCP port.

    Type a port number between 1 and 65535, such as 443.

  3. Click Check Port.

    Submit the form to run the connectivity check.

  4. Review the result.

    The tool returns the resolved IP address, the port and the connection status.

TCP Port Checker FAQ

What does the port checker do?

It attempts a TCP connection to a specified host and port and reports whether the connection succeeds, along with the resolved IP address.

What is a TCP port?

A numbered endpoint, from 1 to 65535, that identifies a specific service or application running on a host.

What does an open port mean?

It means the tool was able to establish a TCP connection, indicating a service is actively listening on that port.

Can I check any host on the internet?

This tool is intended for checking hosts and ports you are authorized to test. Be mindful of the target network's policies before testing.
