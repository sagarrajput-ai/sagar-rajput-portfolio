HOW TO USE

How to access the Secure Port Scanner

  1. Request an access PIN.

    Contact Sagar Rajput to request a limited-use access PIN for the scanner.

  2. Enter the PIN.

    Type the provided PIN into the Access PIN field and submit.

  3. Run an authorized scan.

    Once inside, enter a hostname or IP address you own or are authorized to test, choose a TCP port range, confirm authorization, and start the scan.

Secure Port Scanner FAQ

What is the Secure Port Scanner?

A TCP port scanning tool that checks which ports are open and reachable on an authorized host, protected behind a limited-use access PIN.

Why does this tool require a PIN?

Access is restricted to prevent misuse. Each PIN allows a limited number of scans and is issued only for authorized testing.

How do I get an access PIN?

Contact Sagar Rajput directly, such as through the email link in the site footer, to request access.

Can I scan any host on the internet?

No. The scanner is intended only for hosts and networks you own or have explicit authorization to test. You must confirm authorization before each scan.

What does the scanner return?

For each authorized scan, it reports which TCP ports in the selected range are open, along with the resolved IP address and detected service names.
