IP Calculator FAQ

What does this IP calculator do?

It calculates the network address, broadcast address, subnet mask, host mask, first and last usable host, total addresses, usable hosts and CIDR prefix from an IPv4 address entered in CIDR notation.

What format should I enter?

Enter an IPv4 address followed by a CIDR prefix, such as 192.168.10.0/24.

What is the difference between total addresses and usable hosts?

Total addresses includes every address in the subnet. Usable hosts excludes the network address and broadcast address, which are reserved at each end of the range.

What is a host mask?

A host mask, also called a wildcard mask, is the inverse of the subnet mask. It shows which bits of the address identify the host rather than the network.
