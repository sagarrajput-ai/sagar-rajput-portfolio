HOW TO USE

How to calculate an IP address range

  1. Enter the starting IP address.

    Type the first address in the range, such as 192.168.10.10.

  2. Enter the ending IP address.

    Type the last address in the range, such as 192.168.10.50.

  3. Click Calculate Range.

    Submit the form to run the calculation.

  4. Review the results.

    The tool returns the start IP, end IP, total number of addresses and the IP version.

IP Range Calculator FAQ

What does this IP range calculator do?

It calculates the total number of IP addresses between a starting and ending IP address, and identifies whether the range is IPv4 or IPv6.

Can I calculate IPv6 ranges?

Yes. Enter two IPv6 addresses and the tool will identify the range as IPv6 and calculate the total addresses.

Can I mix IPv4 and IPv6 addresses?

No. Both the start and end address must be the same IP version.

Why must the start IP be less than or equal to the end IP?

The calculator measures the range between two addresses, so the start address must come before or be equal to the end address for the calculation to be valid.
