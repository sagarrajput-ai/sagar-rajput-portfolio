HOW TO USE

How to generate a multi-vendor ACL configuration

  1. Select the target platform.

    Choose from Cisco IOS/IOS-XE, Cisco ASA, Aruba CX, ArubaOS-Switch, Pica8/PicOS, FortiGate or Palo Alto PAN-OS.

  2. Define each access rule.

    For each rule, enter a description, source networks, destination networks, protocol, action (permit or deny) and destination ports.

  3. Add more rules if needed.

    Build up to 20 rules in a single configuration.

  4. Click Generate Configuration.

    Submit the form to generate vendor-specific syntax.

  5. Review and copy the configuration.

    Use the Copy Configuration button to copy the generated output.

ACL Generator FAQ

What is a network ACL?

An access control list (ACL) is a set of rules that permit or deny network traffic based on source, destination, protocol and port.

Which platforms does this generator support?

Cisco IOS/IOS-XE, Cisco ASA, Aruba CX, ArubaOS-Switch, Pica8/PicOS, FortiGate and Palo Alto PAN-OS.

How many rules can I build at once?

Up to 20 rules in a single configuration.

Can I use "any" for source or destination?

Yes. Entering "any" matches all sources or all destinations for that rule.

Should I use the generated configuration directly in production?

The output is a starting reference. Always review the generated syntax against your platform version and test in a controlled environment before applying it to production.
